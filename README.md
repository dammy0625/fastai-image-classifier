# fastai-image-classifier
a cat or dog simple image clsssifier project # Image Classifier (fast.ai Lesson 2)

A cat vs. dog classifier built with fastai (ResNet) and served through a Gradio web app.

## What I did
- Trained an image classifier with fastai on Kaggle
- Exported the model with learn.export()
-  Wrapped it in a Gradio interface for browser-based predictions

## Run it yourself
1. Train and export the model (see the fast.ai Lesson 1 and 2 notebooks)
2. pip install -r requirements.txt
3. python app.py

Note: Hugging Face Spaces no longer offers free Gradio hosting, so I demoed it with a temporary Gradio share link.
